# How to Pull Request! 
1. Complete all of the code you need on your branch (eg. ```your-branch```)
2. Go to https://github.com/Velossoraptor/rex-and-found/pulls
3. Click 'New pull request' (green button, top right)
4. See table of branches under "Compare and review just about anything", and click ```your-branch```
5. Find the green button labeled 'Create pull request'
6. If the request says "Able to merge. These branches can be automatically merged." Feel free to click merge
7. *If the request does not say "Able to merge.",* **Do Not Merge.** Message someone on the team like Talia or Ryan and ask them to take a look first please. 
8. (If something goes wrong, let Talia or Ryan know- It shouldn't be a huge deal to fix if we catch an issue early!)
